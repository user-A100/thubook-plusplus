# THU 本地点评库

这是一个纯本地 Chromium Manifest V3 扩展。用户从自己电脑选择点评备份后，扩展会在 `thubook.help` 的课程详情页中补充显示公开页面缺少的点评。

## 隐私和边界

- 不调用点评提交接口。
- 不向网站、GitHub 或其他服务器上传备份。
- 公开仓库不包含任何点评正文备份，也不提供内含私人数据的安装包。
- 不修改网站后端、前端文件或公开数据。
- 只有安装扩展并自行载入备份的浏览器能看到补充点评。
- 仅对当前课程执行同源 GET 请求，读取公开的 `/data/courses/<id>.json` 用于去重。
- 扩展权限只有 `storage` 和 `thubook.help/thucourse/*` 页面注入。

## 安装

1. 下载或克隆本仓库。
2. 打开 Chrome/Edge 的扩展管理页。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择直接包含 `manifest.json` 的仓库文件夹。
6. 点击扩展图标，选择“管理本地库”。

网站页内的“管理本地库”和右下角按钮通过扩展后台打开管理页，不直接跳转 `chrome-extension://` 地址，避免被 Helium 等拦截器屏蔽。

## 导入本地备份

在管理页点击“选择其他 JSON 文件”，选择仅保存在自己电脑上的点评备份。

扩展使用 `data/current-review-index.json` 中的公开点评 ID 排除网站现存记录。该索引只有数字 ID，不包含点评正文、评分、成绩或时间。导入文件只写入当前浏览器的扩展存储，不会被提交到网站或 GitHub。

支持的格式包括：

- 点评数组；
- `{ "results": [...] }`；
- `{ "reviews": [...] }`；
- 单条 `new_*.json`；
- 与点评文件一起选择 `old_to_new_id_map.json`。

分页 API 响应通常不是完整备份；导入前应确认 JSON 含有需要恢复的全部点评。

## 页面效果

- 课程详情页只显示公开课程文件中没有的点评。
- 每条补充点评都标记为“来自本地备份 / LOCAL”。
- 统计页会在当前浏览器中合并本地补充数据，并标明合并统计仅本机可见。
- 网站统计和当前课程点评均在页面刷新时重新读取。

## 更新公开 ID 索引

```powershell
npm run snapshot-current
```

该命令只生成网站当前公开点评的数字 ID 列表，不保存点评内容。

## 验证

```powershell
npm test
npm run check
python tests/extension_smoke.py
```

浏览器测试使用运行时生成的单条临时点评，不需要或读取任何私人备份，并验证：

- 本地导入和课程页补显；
- 公开 ID 索引去重；
- 统计页本地合并说明；
- 两个管理页入口连续打开；
- 点评提交 POST 为 0，原点评 API 请求为 0。
